## Общее для ДЗ 2–5

Во всех работах используется локальная модель SmolLM2-135M-Instruct (файл модели около 100 МБ устанавливается вместе с пакетом `llm-smollm2`) и библиотека `llama-cpp-python`. Модель понимает в основном английский язык, поэтому запросы и данные в ноутбуках на английском. Работы проверялись на Python 3.13.

```
pip install llama-cpp-python llm-smollm2 wordllama pydantic psutil pandas numpy matplotlib scikit-learn rank_bm25 langchain-core langchain-classic "langchain-community<0.4" datasets ragas rapidfuzz jupyter
```

- `llama-cpp-python` при установке собирается из исходников, для этого нужен компилятор C++. Если сборка не проходит, можно поставить готовую версию: `pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu`.
- `langchain-community` нужен версии ниже 0.4: более новые версии несовместимы с `ragas` 0.4.

Каждый ноутбук выполняется сверху вниз, время работы 1–2 минуты. Замеры времени и скорости при повторном запуске немного отличаются.
